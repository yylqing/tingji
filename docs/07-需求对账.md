## 三、本轮补的功能

| 功能 | 端到端验证 |
|---|---|
| **手动干预（FR-C4）** | 改说话人/合并/删除 3 个操作均返回 `rebuild:true`；段数 168→167；单测覆盖删除重编号与合并 |
| **导出（G2 补强）** | `/api/jobs/{id}/export?format=srt\|vtt\|txt`，实测 200 / 12KB / 中文文件名用 RFC5987 编码 |
| **删除任务** | `DELETE /api/jobs/{id}?keep_archive=1`，清理 DB + work + output |
| **设置页（G6）** | `/api/status` 返回 Python/ffmpeg/Ollama/CPU/内存/模型就绪状态 + 12 项关键配置 |

### 过程中修的 4 个 bug

1. **中文文件名导致导出 500**：`Content-Disposition` 用 latin-1，改成 RFC 5987 编码；
2. **删除段触发 UNIQUE 冲突**：`idx` 整体前移会撞唯一约束，改成先 +100000 再 -100001 两步；
3. **状态接口字段不存在**：`cfg.llm.model` 实际配置在 `correction/summary/roles/refine` 各自的 model；
4. **静音间隙的短句无说话人**（29/168 段）：补"归给时间上最近的 turn"的兜底。

## 四、剩余缺口与建议优先级

| 优先级 | 缺口 | 说明 | 预估 |
|---|---|---|---|
| **P1** | 声纹回写（C5） | 校对时听到清晰的一段，一键入库，省去重录 | 0.5 天 |
| **P1** | 资源守卫（H2） | 跑前检查可用内存/磁盘，不足则拒绝并提示 | 0.5 天 |
| **P1** | 日志页（G7） | 现在只能看单任务事件流 | 0.5 天 |
| **P2** | 限流（I2） | 令牌鉴权有了，但没有 QPS 限制 | 0.5 天 |
| **P2** | 通知（H4） | 支持 webhook / 系统通知 | 1 天 |
| **P2** | 重叠段重转写（C7） | 需换支持分离的模型，时间戳仍是坑 | 3 天+ |

> 结论：**P0 全部完成**（新增 B5.2 幻觉过滤、B2.2 静音门控两条，均已实现）；剩下的 4 条 P0/P1 缺口里，词级时间戳成本最高、收益也最直接（字幕/定位），
> 建议优先做"声纹回写 + 资源守卫"这两条半天能完成的，再排词级对齐。
