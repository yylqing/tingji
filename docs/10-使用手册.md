> 适用版本：v0.33.x　｜　最后更新：2026-11-03

本手册面向使用者，讲清楚「怎么装、怎么用、怎么调」。技术原理见

## 1. 安装

### 1.1 环境要求

| 项 | 要求 |
|---|---|
| 系统 | macOS 13+（Apple Silicon 推荐）/ Linux |
| Python | 3.11–3.12（推荐 3.12） |
| 内存 | 8 GB 起；16 GB 可跑长会 + 本地 LLM |
| 磁盘 | 模型约 6 GB（Paraformer+SenseVoice+分割+声纹+Nano） |
| 依赖 | `ffmpeg`（`brew install ffmpeg`） |
| 可选 | Ollama + `qwen3.5:9b`（整理稿/纪要；不装也能用） |

### 1.2 安装步骤

```bash
git clone git@github.com:yylqing/tingji.git
cd tingji

uv venv .venv-funasr --python 3.12
.venv-funasr/bin/python -m pip install -r code/requirements.txt

cp code/config/config.example.yaml code/config/config.yaml
```

首次运行会自动下载 ASR 模型（约 2 GB，走 ModelScope）；国内网络无需代理。

### 1.3 启动

```bash
PYTHONPATH=code .venv-funasr/bin/python -m app.cli service --port 8000
```

终端会打印：

```
👀 监听 …/input｜⚙️ 队列处理｜🌐 Web :8000
🖥  本机：  http://127.0.0.1:8000/?token=xxxx
🌐 局域网：http://192.168.x.x:8000/?token=xxxx
```

令牌也在 `code/config/access_token.txt`。首次带 token 访问后浏览器会写入 cookie，
之后直接访问 `/` 即可。

## 2. Web 界面

### 2.1 任务页 `/`

- 顶部「上传并处理」：选择音频（wav/mp3/m4a/aac/webm/opus…）入队；
- 列表显示：文件、时长、状态、进度、阶段；
- 每行操作：**查看**、**归档/恢复**、**删除**（删除会删输出，Obsidian 笔记不动）；
- 「显示已归档」勾选后可看到归档任务。

把文件直接丢进 `input/` 效果相同（自动入队，重复文件按 sha256 跳过）。

### 2.2 任务详情 `/job/<id>`

| 区块 | 用途 |
|---|---|
| 顶部 | 状态、时长、Obsidian 路径；导出 SRT/VTT/TXT、声纹入库、重新认名、校对说话人、重跑 |
| 处理进度 | 13 个阶段的耗时与状态（跳过/失败会标出） |
| 智能纪要 | 类型徽章、摘要、章节表、决议、待办、关键词 |
| 整理稿 | LLM 分段润色后的可读文本 |
| 逐字稿 / 清洗稿 / 原文 | 逐句列表，可试听、改文字、**改说话人**、**合并下一段**、**拆分**、删除 |

**校对流程建议**：

1. 先看「逐字稿」，遇到一句里有两个人 → 点「拆分」→ 选停顿候选或手填毫秒；
2. 两段分别「改说话人」；
3. 全部改完点「重跑」，重建整理稿与纪要。

标签页支持深链：`/job/<id>?track=final`（`para/final/clean/raw`）。

### 2.3 热词页 `/hotwords`

- 每行一个词，权重越高越优先；
- 热词参与两级匹配：L1 直接给 ASR 做偏置，L2 做事后拼音模糊纠正；
- 人名、地名、产品名、英文术语都建议登记。

### 2.4 声纹库 `/voices`

- **登记**：输入姓名，按 S1/S2/S3 三句录音（约 31 秒），可现场录或选文件；
- **追加**：给已有人物补录音（换设备后尤其需要）；
- **信道列**：显示这个人的样本被分成几组（几种设备），`单信道` 表示只在一种设备录过；
- **样本**：展开可看每条样本的簇号、来源、质量、时间，可单条删除；
- **改名 / 删除**：删除人物会同时删掉其全部样本。

### 2.5 设置 `/settings`

按分组折叠，改动写入 `config/overrides.yaml`，对**新任务**立即生效；
`server.*` 需要重启服务。

### 2.6 日志 `/logs`

按级别过滤，排查失败任务时先看这里。

## 3. 关键功能说明

### 3.1 引擎怎么选

`asr.provider: auto`（默认）会在识别前探测说话人数与时长：

| 条件 | 引擎 | 适合 |
|---|---|---|
| ≥20 分钟 / ≥3 人 / 1 人 | Paraformer | 会议、讲座（快，词级时间戳精确） |
| 2 人一对一 | Fun-ASR-Nano | 对话、访谈、私人录音（句子更连贯） |
| 其它 | Fun-ASR-Nano | 碎片化、安静录音 |

想固定引擎：设置页选，或命令行 `--asr funasr|sensevoice|funasr_nano`。

### 3.2 声纹认名

- 同一设备录的样本相似度约 0.9，**换设备会掉到 0.3 左右**；
- 所以建议每个常用设备（网页麦克风 / 手机 / 车机 / 会议麦）各录 1–2 段；
- 系统按「设备簇」分别比对取最高分，配置项：
  `match_threshold`（0.35，跨设备可降到 0.30）、`match_margin`（0.08）、
  `channel_threshold`（0.75）、`max_channels`（4）；
- 认名是保守策略：分数或领先幅度不够就标「低置信」而不硬认。

### 3.3 热词与规则

- 热词库：`/hotwords` 页面维护；
- 正则纠错：`code/config/rules.txt`，格式 `查找正则 = 替换`，例如

  ```
  欧拉玛 = Ollama
  (艾特|at)\s*(\w+)\s*(点|dot)\s*(com|cn) = @\2.\4
  ```

  执行顺序在热词之后、整理稿之前。

### 3.4 数字规范化（ITN）

`三百毫秒 → 300毫秒`、`十五六个 → 15~16个`、`三五百台 → 300~500台`；
`二十三岁`、`三心二意` 不会误伤。

### 3.5 Obsidian 归档

```
录音笔记/
└── <类型：会议纪要/日常对话/重要时刻/访谈/讲座/备忘/其他>/<年>/
    └── <日期 标题>/
        ├── 同名.md     总结 + 章节 + 待办 + 整理稿正文
        ├── 同名.m4a    音频
        ├── 同名.srt    字幕
        └── 同名.txt    纯文本
转写稿/<年>/
├── 同名-逐字稿.md
└── 同名-整理稿.md
```

配置 `obsidian.vault_path` 填 vault 路径即启用；`notes_by_type` 控制是否按类型分目录。

## 4. 命令行

```bash
PYTHONPATH=code .venv-funasr/bin/python -m app.cli <命令>
```

| 命令 | 作用 |
|---|---|
| `run <文件>` | 转写单个文件（`--asr`、`--speakers`、`--force`） |
| `ingest <文件>` | 只入队，不阻塞 |
| `service` | 监听目录 + 队列 + Web（`--port`、`--host`） |
| `serve` | 只开 Web（不监听目录） |
| `scan` | 扫描一次 `input/` |
| `watch` | 只监听目录 |
| `worker` | 只跑队列 |
| `autostart install\|uninstall\|status` | launchd（macOS，TCC 下可能失败，建议用登录项） |
| `selfcheck` | 环境自检（ffmpeg、模型、Ollama、磁盘） |

## 5. 开机自启（macOS）

```bash
bash code/scripts/install-login-item.sh      # 安装（会请求控制 System Events）
bash code/scripts/install-login-item.sh --remove   # 卸载
```

原理：登录项调用 `~/Library/Application Support/TingJi/start.sh`，由 Terminal 启动，
绕过 launchd 对 `~/Documents` 的 TCC 限制。详见开发说明 §10.4。

## 6. 对接其他客户端（OpenAI 兼容）

服务同时提供 OpenAI 风格的转写接口，可直接给 Memos / Open WebUI 等使用：

| 字段 | 值 |
|---|---|
| 端点 | `http://<本机IP>:8000/v1` |
| API 密钥 | `config.yaml` → `openai_api.api_key` |
| 模型 | `tingji-asr`（快）/ `tingji-asr-hq`（带说话人）/ `whisper-1`（别名） |
| 语言 | `zh` |
| 提示词 | 热词，如 `人名：刘益清、李彦昆。术语：胎心、社康。` |

`-hq` 会把「说话人1：…」写进 `text` 字段，并在 `verbose_json` 里给结构化段落。

详细字段见 [API 文档](11-API文档.md)。

## 7. 故障排查

| 现象 | 处理 |
|---|---|
| 网页打不开 | `curl http://127.0.0.1:8000/api/health`；看 `output/.runtime/logs/service.log` |
| 提示 401 | 带令牌访问 `/login`，或 `/?token=...` |
| 任务失败「未检测到有效语音」 | 音频确实没声音，或阈值 `asr.min_speech_ratio` 偏高 |
| 说话人全是「未知」 | 声纹库没登记；或分离失败，看任务事件里 `diarized` 那行 |
| 认名分数 0.3 左右 | 跨设备，按 §3.2 补样本或降阈值 |
| 整理稿没生成 | Ollama 没起或 `refine.enabled=false` |
| 端口冲突 | `pkill -f "app.cli .*service"` 后重启 |
| 模型加载报 `not registered` | 重启服务（缓存被污染），v0.29.4 起会自动重置重试 |

## 8. 数据与备份

| 数据 | 位置 |
|---|---|
| 数据库 | `output/.runtime/data/app.db` |
| 中间产物 | `output/.runtime/work/<job_id>/` |
| 声纹 | 数据库 `voiceprints` 表 |
| 逐字稿/整理稿 | `output/<任务名>/` |
| Obsidian 笔记 | 你的 vault（`录音笔记/`、`转写稿/`） |

备份：数据库 + vault 即可；`work/` 可以随时删（会重算）。
