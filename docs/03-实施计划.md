## 3. 关键实现细节（避免返工）

### 3.1 模型只加载一次

```python
# engines/asr_funasr.py（要点）
class AsrEngine:
    _model = None

    @classmethod
    def get(cls):
        if cls._model is None:
            from funasr import AutoModel
            cls._model = AutoModel(
                model="paraformer-zh",
                vad_model="fsmn-vad",
                punc_model="ct-punc",
                spk_model="cam++",
                device="cpu",
                disable_update=True,
            )
        return cls._model
```

- 加载耗时实测 14s（热缓存），**必须常驻**，不可每任务重建。
- 若后续要跑 LLM，先 `del model + gc.collect()` 再调 Ollama，避免 4.35GB + 7GB 叠加。

### 3.2 阶段协议

```python
# pipeline/base.py
class Stage(Protocol):
    name: str
    weight: float          # 进度权重
    def run(self, ctx: JobContext) -> JobContext: ...
```

- `ctx` 携带 `job_id`、路径、已加载数据、进度回调。
- 每个 stage 结束即写 `work/<job_id>/<stage>.json`，并更新 DB `stage`。
- 异常统一包装为 `PipelineError(code, msg)`。

### 3.3 时间戳不可变

纠错阶段返回的文本按 `seg_id` 回填；**代码层拒绝**任何携带时间戳的输出字段。合并时取被合并段的 `min(start) / max(end)`。

### 3.4 LLM 调用模板

```python
async def chat(prompt: str, *, model="qwen3.5:9b-q4_K_M", json_mode=True, think=False):
    payload = {
        "model": model, "prompt": prompt, "stream": False,
        "think": think,                       # 必须显式关闭
        "format": "json" if json_mode else None,
        "options": {"temperature": 0.2, "num_predict": 1200},
        "keep_alive": 0,                      # 用完即卸，省内存
    }
    # 校验 response 非空；为空则重试一次并记录 E_LLM_EMPTY
```

> `format: "json"` 是 Ollama 的结构化输出开关，配合 `think:false` 可显著降低解析失败率。

### 3.5 声纹比对

```python
def match(centroid, vectors, thr=0.72, margin=0.05):
    sims = sorted(((cosine(centroid, v), spk) for spk, v in vectors), reverse=True)
    if not sims: return None, 0.0, 0.0
    top1, spk1 = sims[0]
    top2 = sims[1][0] if len(sims) > 1 else 0.0
    if top1 >= thr and (top1 - top2) >= margin:
        return spk1, top1, top1 - top2
    return None, top1, top1 - top2
```

### 3.6 原子写

```python
def atomic_write(path: Path, content: str):
    tmp = path.with_suffix(path.suffix + ".tmp")
    with open(tmp, "w", encoding="utf-8") as f:
        f.write(content); f.flush(); os.fsync(f.fileno())
    os.replace(tmp, path)
```

### 3.7 文件稳定性

```python
def wait_stable(path: Path, checks=3, interval=2.0, max_rounds=60) -> bool:
    """大小连续 (checks-1) 次不变，且 ffprobe 能读出时长，才视为就绪。"""
    last, stable = -1, 0
    for _ in range(max_rounds):
        size = path.stat().st_size if path.exists() else -1
        if size > 0 and size == last:
            stable += 1
            if stable >= checks - 1:
                return probe_duration(path) > 0
        else:
            stable = 0
        last = size
        time.sleep(interval)
    return False
```

## 6. 测试策略

| 层 | 范围 | 工具 | 门槛 |
|---|---|---|---|
| 单元 | 清洗规则、时间戳、渲染、相似度、文件名清洗 | pytest | 覆盖率 ≥70%（rules/render 需 ≥85%） |
| 集成 | 每阶段 fixture 输入→输出 | pytest + JSON fixture | 全部通过 |
| 端到端 | 3 合成 + 2 真实脱敏 | pytest -m e2e | 成功率 100% |
| 质量回归 | 基准集 CER / 说话人准确率 | 自研评测脚本 | CER ≤12%，说话人误差 ≤±1 |
| 手工 | 全 FR 验收 | 检查表 | 按 PRD §11 |

**关键回归用例（必须有）**：

1. `嗯，那个，我们这个季度的目标是翻倍啊` → 清理正确、不误删"那个方案"。
2. `ClickHouse` 被误识为"认批" → 术语表纠错生效。
3. 说话人 3 人聚类 → 不与已注册人员混淆。
4. 归档重复执行 → 笔记仍只有一份。
5. LLM 返回空 → 自动重试后成功或降级。
6. 纠错输出 `seg_id` 缺失 → 被校验器拒绝并回退原文。
7. 断网执行全流程 → 成功。
