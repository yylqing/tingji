# 正则纠错规则：每行「查找模式 = 替换式」，两侧空格会去掉，# 开头为注释。
# 查找模式是正则，替换式支持 \1 \2 反向引用。规则在热词替换之后执行。
# 用于处理"固定格式"的错：单位、邮箱、网址、反复出现的同音错字。

# —— 同音误写的术语 ——
欧拉玛 = Ollama
奥拉玛 = Ollama

# —— 单位 ——
毫安时 = mAh
赫兹 = Hz
伏特 = V

# —— 邮箱：艾特 xxx 点 com ——
(艾特|at)\s*([A-Za-z0-9_.-]+)\s*(点|dot)\s*(com|cn|net|org) = @\2.\4

# —— 网址：xxx 点 com ——
(?<![@A-Za-z0-9])([a-z0-9-]{2,})\s*点\s*(com|cn|net|org|io) = \1.\2
